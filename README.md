# Tripleten web_project_homeland
Nombre del proyecto: Web_project_homeland
Descripción del proyecto: Página web de tripleten utilzando HTML y CSS; en donde se presentan historias y fotografías de ciudades natales de diferentes personas. Se utilizó como guía un diseño base de figma, haciendo responsivo el sitio web. 
Planes de mejora: Añadir un menú principal, añadir mas historias, agregar videos de los lugares en lugar de fotografías para hacerlo mas dinamico
